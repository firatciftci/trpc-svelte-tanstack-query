# Security policy

## Supported versions

Security fixes go into the latest release. Until 1.0, that means the latest `0.x` version.

## Reporting a vulnerability

Do not open a public issue for a security problem. Report it privately through [GitHub's private vulnerability reporting](https://github.com/firatciftci/trpc-svelte-tanstack-query/security/advisories/new) instead.

Include what you found, the versions affected, and the steps or code to reproduce it. You'll get a reply within a week. Once the problem is confirmed, I will work on a fix with you, publish a release, and credit you in the advisory unless you would rather stay anonymous.

If the problem is in tRPC or TanStack Query rather than in this package, report it to [tRPC](https://github.com/trpc/trpc/security) or [TanStack Query](https://github.com/TanStack/query/security) directly.
